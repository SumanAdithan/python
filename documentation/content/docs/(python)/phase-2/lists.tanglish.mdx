## list

Python oda `list` na JavaScript array oda equivalent. Idhu ordered, create pannina apparam
change pannalam, duplicate values-um vechikalam.

JavaScript:

```js
const fruits = ['apple', 'banana', 'cherry'];
```

Python:

```python
fruits = ["apple", "banana", "cherry"]
```

Same idea than — square brackets, comma-separated values. `len()` size-a kudukkum:

```python
len(fruits)   # 3
```

## Indexing

JS arrays maadhiri than, indexing `0`-la irundhu start aagum.

```python
fruits[0]   # "apple"
fruits[1]   # "banana"
```

Python-la **negative indexing** nu oru feature irukku — last-la irundhu count panna clean
way:

```python
fruits[-1]   # "cherry" (last item)
fruits[-2]   # "banana" (second-last item)
```

JS-la idha pannanum na `arr.at(-1)` use pannanum; Python-la `-1` andha bracket-kulla direct-a
work aagidum.

## Slicing

`list[start:stop]` vechi sub-list-a edukalam. `range()` maadhiri than, `stop` **include
aagadhu**.

```python
fruits = ["apple", "banana", "cherry", "date"]

fruits[1:3]    # ["banana", "cherry"]
fruits[:2]     # ["apple", "banana"]   (start default-a 0)
fruits[2:]     # ["cherry", "date"]    (stop default-a end)
fruits[:]      # ["apple", "banana", "cherry", "date"]  (full copy)
```

JavaScript-la idhukku close-a irukura option `arr.slice(start, stop)` — same start/stop
behavior than, method form-la irukku.

Oru common trick — slice vechi list-a reverse pannalaam:

```python
fruits[::-1]   # ["date", "cherry", "banana", "apple"]
```
