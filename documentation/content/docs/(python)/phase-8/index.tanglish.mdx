## Goals

```python
async def get_user():
    data = await fetch_data()
    return data
```

Puriyanum:

- `def` — oru normal function
- `async def` — oru asynchronous function
- `await` — async operation mudiyum varaikkum wait pannradhu

Naalaikku idhu genuinely podhum — idhu pathi innoru page, apparam inniku ku over.

## Cheat sheet

```text

───────────────────────────────────────────────────────
function getUser() { }                     def get_user():

async function getUser() {                 async def get_user():
```
