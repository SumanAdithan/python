---

## Variables

JavaScript:

```js
const name = 'John';
let age = 25;
```

Python:

```python
name = "John"
age = 25
```

Adhu than. Python-la `const`, `let`, `var` edhuvum kidayathu — nee oru value assign
pannuna podhum, andha value-a vechu Python type-a automatic ah find pannikkum:

```python
name = "John"
age = 25
price = 99.99
active = True
```

Python **dynamically typed** language, so idhu technically allowed:

```python
value = 10
value = "hello"
```

## Constants

Python-la real `const` keyword kidayathu. Convention padi, **uppercase name** vechina
"idha constant-a treat pannu"-nu artham:

```python
MAX_USERS = 100
API_VERSION = "v1"
```

Idhu just oru naming convention than — nee value-a change panna edhuvum block panradhu
illa. `const` maadhiri Python force pannadhu.
