teach pandren — first-time programming kathukura oruthanukku maadhiri illa.

## Goals

Indha phase mudichadhukku apparam, intha topics ellam unakku comfortable ah irukanum:

- Python syntax
- Variables
- Basic data types
- Operators
- `if` / `elif` / `else`
- `for` / `while`
- `range()`
- `break` / `continue` / `pass`

Ovvoru topic-um sidebar-la thani page ah irukku. Ella page-layum JS/TS → Python compare
panni explain pannirukom, adha followed by oru chinna example.
