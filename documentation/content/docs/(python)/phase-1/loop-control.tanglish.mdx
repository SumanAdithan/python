title: break, continue & pass
description: Loops-a control pannradhu, mattrum "innum onnum implement pannala" keyword
---

## break

JS-la iruntha same concept than — loop-a completely stop pannidum.

```python
for i in range(10):

    if i == 5:
        break

    print(i)
```

```text
0
1
2
3
4
```

## continue

Indha iteration-oda remaining part-a skip panni, next iteration ku pogum.

```python
for i in range(5):

    if i == 2:
        continue

    print(i)
```

```text
0
1
3
4
```

## pass

Idhu Python-specific — nee occasionally paapa.

```python
def some_function():
    pass
```

Idhu **"ippodikku edhuvum pannadhe"**-nu artham. Syntactically valid code venum aana logic
innum implement pannala-nu bothu idhu useful:

```python
if condition:
    pass
```
