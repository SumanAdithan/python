## *args — edhavadhu number of positional arguments

`*args`, extra positional argument ella onnaiyum oru **tuple**-a collect pannum.

```python
def total(*numbers):
    return sum(numbers)

total(1, 2, 3)       # 6
total(1, 2, 3, 4, 5) # 15
```

JS oda equivalent rest parameters than:

```js
function total(...numbers) {
  return numbers.reduce((a, b) => a + b, 0);
}
```

Same idea than, symbol matum different — Python `*` use pannum, JS `...` use pannum.

## **kwargs — edhavadhu number of keyword arguments

`**kwargs`, extra `name=value` argument ella onnaiyum oru **dict**-a collect pannum.

```python
def create_user(**details):
    print(details)

create_user(name="John", age=25)
# {"name": "John", "age": 25}
```

JS-la close-a irukura equivalent, matum oru object accept pannradhu than:

```js
function createUser(details) {
  console.log(details);
}

createUser({ name: 'John', age: 25 });
```

Difference: Python-la caller edhuvum braces-la wrap panna vendam — `**kwargs`, pass pannina
named arguments ellathayum edukkum.

## Naming just convention than

`args` mattrum `kwargs` keywords illa — `*` mattrum `**` matum than matter aagum. Nee
vera edhavadhu name vechikalam, aana `*args`/`**kwargs` than almost ella Python code-layum
nee paakura convention.

## Ondra serthu use pannradhu

Oru function regular parameters, `*args`, mattrum `**kwargs` — moonu type-um oru saathiyum
accept pannalam, eppovum indha order-la than:

```python
def example(a, b, *args, **kwargs):
    print(a, b, args, kwargs)

example(1, 2, 3, 4, x=5, y=6)
# 1 2 (3, 4) {'x': 5, 'y': 6}
```
