## Default parameters

Oru parameter-ku default value kudu, adhu optional aagidum — JS maadhiri than idea.

JavaScript:

```js
function greet(name = 'Guest') {
  console.log(`Hello ${name}`);
}
```

Python:

```python
def greet(name="Guest"):
    print(f"Hello {name}")

greet()          # Hello Guest
greet("John")    # Hello John
```

## Keyword arguments

Python-la nee `parameter_name=value` vechi function-a call pannalaam, **edho oru order-lam**:

```python
def create_user(name, age):
    print(name, age)

create_user(age=25, name="John")   # John 25
```

JS-la idhukku direct-a equivalent kidayathu — close-a irukura option object parameter-a
destructure pannradhu, adhu caller-a named values pass pannanum-nu force pannum:

```js
function createUser({ name, age }) {
  console.log(name, age);
}

createUser({ age: 25, name: 'John' });
```

Python-la same "name vechi call pannradhu" convenience free-a kidaikkum, edhuvum object-la
wrap pannama — positional mattrum keyword calls rendum same function-la work aagum:

```python
create_user("John", 25)         # positional — idhuvum work aagum
create_user(name="John", age=25) # keyword — idhuvum work aagum
```

Function-la multiple parameters irundha, keyword arguments romba useful — ovvoru call-um
self-documenting ah aagum.
