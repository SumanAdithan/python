title: class & object
description: Class define pannradhu, object create pannradhu — new keyword edhuvum illa
---

## class

Class na objects create pannradhukku oru blueprint. Keyword nee already ariyum vaarthai than:

TypeScript:

```ts
class User {
}
```

Python:

```python
class User:
    pass
```

Functions maadhiri than same pattern — `{ }` ku badhila `:` + indentation. `pass` na "ippodikku
empty body" nu artham (idha Phase 1-lame paartha).

## object

**object** (Python idha **instance** nu solum) na class-la irundhu create pannina oru real
value.

TypeScript:

```ts
const user = new User();
```

Python:

```python
user = User()
```

Unlearn pannanum-na oru thing: **Python-la `new` keyword edhuvum kidayathu**. Class name-a
function maadhiri call panna, object create aagidum.
