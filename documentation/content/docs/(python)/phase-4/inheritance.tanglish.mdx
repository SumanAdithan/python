## Inheritance

TypeScript oda `extends`, Python-la class name-ku apparam **parentheses** aaga maarum.

TypeScript:

```ts
class Animal {
  name: string;

  constructor(name: string) {
    this.name = name;
  }

  speak(): string {
    return `${this.name} makes a sound`;
  }
}

class Dog extends Animal {
  speak(): string {
    return `${this.name} barks`;
  }
}
```

Python:

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return f"{self.name} makes a sound"

class Dog(Animal):
    def speak(self):
        return f"{self.name} barks"

dog = Dog("Rex")
print(dog.speak())   # Rex barks
```

`Dog`, `Animal`-la irundhu ellathayum inherit pannikkum — `__init__`-um sagitham — `speak()`
matum override pannum.

## super()

Child class-ku thani `__init__` venum, aana parent oda setup logic-um run aaganum-nu bothu,
`super()` call pannu — TypeScript-oda constructor-kulla `super(...)` panra same idea than.

TypeScript:

```ts
class Dog extends Animal {
  breed: string;

  constructor(name: string, breed: string) {
    super(name);
    this.breed = breed;
  }
}
```

Python:

```python
class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed
```

Difference: TypeScript direct-a `super(name)` call pannum; Python first `super()` call
pannum (arguments edhuvum illama) parent-oda reference edukkum, apparam adhoda mela
`.__init__(name)` call pannum. Result same than — `Dog` edhavadhu add pannradhukku munnadi
parent oda constructor run aagi `self.name`-a set pannidum.
