Environment variables

Idhukku fix enna na, configuration-a unnoda code-ku veliya vekradhu, environment variables ah — oru file-la ezhudradhu ku pathila, adha run pannura edhavadhu program runtime-la unnoda program ku kudukkura values.

Local development-la, idha manage panna standard way oru .env file — KEY=VALUE pairs irukkura oru plain text file, unnoda project root-la irukkum, unnoda program startup-la idha read pannum. Idhu than last lesson-la nee install pannina python-dotenv package ku exact ah purpose.
